## 📥 Установка

### Шаг 1: Скачай сборку

Перейди в [Releases](https://github.com/M1kLuXamAkLay/Modpacks/releases) и скачай нужную сборку.

### Шаг 2: Распакуй архив

**Windows:**
- Щелкни правой кнопкой на архиве
- Выбери "Распаковать здесь" или используй 7-Zip / WinRAR

**macOS/Linux:**
```bash
unzip "BossRush_1.20.1_forge.zip"
```

### Шаг 3: Переместить в .minecraft

Скопируй содержимое распакованной папки в папку .minecraft:

**Windows:** `C:\Users\[Ваше имя]\AppData\Roaming\.minecraft`

**macOS:** `~/Library/Application Support/minecraft`

**Linux:** `~/.minecraft`

### Шаг 4: Запустить

1. Открой Minecraft Launcher
2. Выбери нужный профиль сборки
3. Нажми "Play"

## 🆘 Помощь

### Java не установлена

Скачай OpenJDK Temurin:
https://adoptium.net/

### Недостаточно RAM

Увеличь выделяемую памяти в Launcher:
- Launcher Settings → Java Settings → Maximum Memory
- Выстави 8-16 GB

### Моды не загружаются

1. Убедись что версия Java совпадает (Java 17+ для 1.20.1)
2. Переустанови Minecraft Launcher
3. Пересоздай папку .minecraft

### Низкий FPS

Попробуй:
- Снизь Render Distance в видео настройках (8-12)
- Выключи Fancy Graphics
- Снизи количество частиц (Minimum)
- Выключи облака
